# GRAMMER.md - 自定义 Simple GPU(sg)语言规格

版本 0.4 · 关联文档: ISA.md(目标指令集)· CMDS.md(命令集)· `compiler.py`(本规格的实现)· `assembly.py`(汇编器)

编译流程:

```
foo.sg ──compiler.py──► foo.S ──assembly.py──► foo.bin(内核镜像,CMDS.md §6.4)──► 模拟器
        模板展开/分配        编码/CRC                      LOAD_KERNEL + LAUNCH
```

## 1. 总览

这是一种面向 SIMT 的结构化汇编语言,每个语言构造直接对应 ISA.md 的指令序列。
编译器**只做模板展开、寄存器分配和标签解析,不做优化** —— 生成的每一条指令都能在本文档里找到出处。

## 2. 词法

| 符号 | 说明 |
|---|---|
| `#` | 到行尾都是注释 |
| `-:` | 常量定义:`名字 -: 数值`,只能在 kernel 以外 |
| `@` | 常量值引用:`@名字`(取该常量的**值**)或 `@名字[偏移]`(从地址 `名字+偏移` **读一个字**) |
| `标识符` | `[A-Za-z_]\w*`;以 `__` 开头的是编译器内部标签,用户不要使用 |
| `关键字` | `kernel` `var` `param` `goto` `when` `uniform` `if` `else` `end` `while` `bar` `exit` `int` `float` `__shared__` `__global__` `ass` `per_warp` `shared` |
| 数字 | 十进制/`0x` 十六进制整数;带小数点或 `f` 后缀 ⇒ float |
| 运算符 | `+ - * / % & \| ^ ~ << >> >>> = == != < <= > >= ( ) [ ] , : @ !`;长符号优先(`-:` 先于 `-`,`<=` 先于 `<`,`>>>` 先于 `>>`) |

- 语句**按行组织**:一条语句一行(块用 `end` 收尾,`if`/`while`/`when` 的条件后跟 `:`)。

## 3. 类型

| 类型 | 说明 |
|---|---|
| `int` | INT32,缺省 |
| `float` | FP32 |

- 整数字面量 → int;带小数点或 `f` 后缀 → float。
- **混合表达式**里 int 自动提升为 float(`i2f`),提升是编译期插入的,无需手写。
- **赋值不做隐式转换**:把一个 float 变量赋给 int 变量要显式 `f2i()`,反之要 `i2f()`,否则报 `E004`。
- 比较:两边类型一致时用对应比较 —— int 用 `setp.lt/le/gt/ge/eq/ne`,float 用 `setp.flt/fle/fgt/fge/feq/fne`;
  一边是 int、一边是 float 时先提升再比较。
- `ldx`/`lds`/`@sym[off]` 的返回类型**由目标变量类型决定**(没有目标上下文时按 int)。
- 取负:int 用 `sub rd, r0, rx`;float 用 `lui rd, -0x80000`(即 0x8000_0000)+ `xor`,只翻符号位。
- `f2i(x)` 显式转换 FP32 → INT32;`i2f(x)` 显式转换 INT32 → FP32。
- `!` 只能作用于**比较式**(把它取反),不能作用于数值:比较表里只有比较谓词,没有"非零即真"。
- `~`(按位取反)与 `& \| ^ << >> >>>`(位运算/移位)**只支持 int**;float 用它们报 `E004`。
- `>>` 是**算术**右移(`sra`,符号位扩展),`>>>` 是**逻辑**右移(`srl`);左移统一 `<<`(`sll`)。

## 4. 声明

### 4.1 常量定义

```
<名字> -: <数值>
const -: 0x02000000
frame_base -: 0x10000000
N -: 16
```

### 4.2 变量声明

```
var <名字列表> [: <类型>]
var N, color, stride   # 缺省 int
var x, y : float       # float
```

- 一条 `var` 只能有一种类型(不支持 `var a : int, b : float`);变量**必须放寄存器**(§8),编译期分配。

### 4.3 参数声明

```
param <名字列表> : <类型> @<符号>[<偏移>]
param N     : int @const[0]
param scale : float @const[4]
```

- `<符号>` 必须是 `-:` 定义的常量(通常是常量区基址 `const`);`<偏移>` 是**编译期常量**(字面量,或 `-:` 定义的常量名 / 常量表达式),必须 4B 对齐且非负,否则 `E010`。
- 展开:内核入口 `ld.g rd, 偏移(r_base)` —— 参数的**读法**由类型决定(int/float 都是 32 位字)。

### 4.4 共享内存声明

```
__shared__ <名字> : <类型>[<长度>] [per_warp | shared]
__shared__ tile : float[64] per_warp
__shared__ red  : int[32] shared
```

- `per_warp`(缺省):每个 warp 私有分区,编译器生成 `wmov rt, wid` + `imad addr, rt, 分区大小, ...`。
- `shared`:所有 warp 共享,**必须用 `bar()` 保证可见性**,否则报 `E013`。
- 容量:总 ≤ 16KB/SM;`per_warp` 的数组按 **×4** 计入(每个 warp 一份)⇒ 超了报 `E011`。
- 元素是 32 位字,所以 `A[i]` 的地址天然 4B 对齐。

### 4.5 全局内存声明

```
__global__ <名字> : <类型>[<长度>]
__global__ data : int[256]
```

- 编译器从 `--global-base`(默认 `0x8000_0000`,DDR)起分配全局地址,编译时打印用量;内核通过 `ldx/stx` 访问。
- 全局数组**只有 shared 语义**(不写 `per_warp`):它是整块设备内存,不随 warp 复制。

### 4.6 插入指令声明

```
ass <指令>
ass mov r21, r0
```

- 指令必须是 ISA.md §5 指令表里的助记符(含 `mov`/`j`/`nop` 等伪指令),否则报 `E014`。
- 原样插入,编译器**不参与**它的寄存器分配与标签解析:里面用到的寄存器/标签要自己写对。

## 5. 表达式

- `a * b + c`(加法的一边是乘法)⇒ int 生成一条 `imad`,float 生成一条 `fma.f32`(单次舍入,ISA §5)。
  其它情形按运算符逐条展开:`add/sub/mul/div/rem`、`fadd/fsub/fmul`。
- int `/` `%` 用**有符号** `div`/`rem`;float 的 `/` `%` 报 `E012`(§8:无 FP 除法/开方)。
- 位运算与移位按 ISA §5.1/§5.4 展开:`& and`、`| or`、`^ xor`、`<< sll`、`>> sra`、`>>> srl`、`~ xori -1`。
  **右操作数是 9 位常量时用立即形式**(`andi`/`ori`/`xori`/`slli`/`srai`/`srli`)⇒ 掩码与移位量不必先装寄存器。
  例:`(idx & 31) << 2` 生成 `andi rt, r_idx, 31` + `slli rd, rt, 2`,两条指令。
- **常量折叠**:整型常量表达式(`4 * 8`、`@base + 16`、`1 << 3`)在编译期算出结果,只生成一次装载;float 不折叠。
- **就地写目标寄存器**:右侧能直接算进目标寄存器时不多做一次位型拷贝(`x = ldx(a)` 直接 `ld.g r_x, ...`);
  但**谓词化时不就地写** —— 算术指令没有谓词字段(ISA §4.2),就地写会在条件不成立时也改掉变量。
- **常驻常量**:出现次数最多的 2 个整型常量(如数组元素大小 `4`)在寄存器充裕时长期占住寄存器,避免每轮循环重新装载。
- 常量装载:立即数能塞进 9 位就用 `addi`;4KB 对齐的大常量用 `lui`;其它情况 2~3 条(`lui` + `addi`,
  或低 12 位不是 9 位可加时再补 `slli`/`add`)—— 代价见 ISA §5.5。**频繁使用的大常量建议放进常量区用 `@` 读**(ISA D8)。
- `0` / `0.0` 直接用 `r0`(ISA §3.1:r0 恒零),不占寄存器也不占指令。

## 6. 语句

### 6.1 赋值

```
<变量> = <表达式>
<数组>[<下标>] = <表达式>
```

- 结果是已算好的寄存器时不再多一条拷贝;否则生成 `add rd, rs, r0`(位型拷贝,**对 float 同样适用**)。
- 数组元素:`imad addr, idx, 4, base` 后 `st.s/st.g`(共享用 `st.s`,全局用 `st.g`)。

### 6.2 无条件跳转

```
goto <标签>
```
展开 `j <标签>`(汇编器展开为 `br.simt`;无条件的跳转不需要收敛点)。

### 6.3 条件跳转

```
when <条件> goto <标签>
uniform when <条件> goto <标签>
```

```
setp.<cond> p1, ...
ipdom <reconv>
@p1 br.simt <目标>, <reconv>
```

- 条件是**比较式**,也可以是它们的 `&&` / `||` 组合:**短路求值**,只判到能定论为止。
  `A && B`(跳转条件是"成立")先判 `A`,不成立就不再算 `B`;`||` 对偶。边界检查就靠它:
  `when (idx >= 0) && (idx < N) goto ok`。
- **收敛点 `<reconv>` 的取法**:目标是**前向**的(标签在后面)⇒ 取目标本身;目标是**后向**的(循环回边)
  ⇒ 取"此语句之后的下一个标签"(循环出口)。
- `uniform` 是**断言**(编译器不验证):条件对所有 lane 一致时可以省掉 `ipdom` 的发散开销。
  本 ISA 的 `br.simt` 一律配对收敛点(汇编器对任何谓词化 `br.simt` 都会补一条 `ipdom`),
  所以生成时把收敛点显式写成目标本身 —— 两条路径都在那里汇合,语义与"不生成 ipdom"等价。
- 用错 `uniform` 会把发散的分支当均匀分支处理,`bar()`/`exit` 的均匀性前提随之失效;拿不准就别写。

### 6.4 条件执行(不发散)

```
when <条件> : <语句>
```

```
setp.<cond> p1, ...
@p1 <访存 / 写回>
```

- 条件只允许**单个比较**。`when A && B : …` 与"`when` 套 `when`"会退化成**分支**(`ipdom` + 条件跳转):
  本 ISA 没有 `andp`/`orp`,一个谓词寄存器存不下两个条件的与。退化后语义不变,但**会短暂发散** ⇒ 里面不能有 `bar()`。
- 只谓词化**有副作用或可能越界**的指令:访存(`ld.g/ld.s/st.g/st.s`)与最终写回。
- 算术指令**不加谓词**:ISA §4.2 里 `fma`/`imad`/`lui` 没有谓词字段,而且它们无副作用 ——
  屏蔽 lane 算出垃圾值,由最后那次谓词化写回挡住(ISA §3.1 的"启动时寄存器清零"保证垃圾值可复现)。
- **谓词化的块同样是"部分 lane 执行"**:里面出现 `bar()` 报 `E006`(被屏蔽的 lane 不会到达屏障)。

### 6.5 条件块

```
if <条件>:
    <语句>
else:
    <语句>
end
```

展开为

```
setp.<cond> p1, ...
ipdom __end
@!p1 br.simt __else, __end     # 条件"不成立"的 lane 走 else;成立的落进 then
__then:
    ...
    j __end
__else:
    ...
__end:
```

无 `else` 时 `__else` 与 `__end` 合并(即 `@!p1 br.simt __end, __end`)。
模板里的 `__then:` 表示「条件成立就落空到这里」,编译器**不额外生成**这个标签(避免无用标签)。

### 6.6 循环

```
while <条件>:
    <语句>
end
```

展开为

```
__loop:
setp.<cond> p1, ...
ipdom __end
@!p1 br.simt __end, __end
    <语句>
j __loop
__end:
```

- **循环条件必须与 lane/warp 无关**(循环次数标量),否则报 `E005`。
- 条件均匀时,循环体内允许 `bar()`(matmul / `relu_swap.sg` 就是这种写法);不均匀时不允许(`E006`)。

### 6.7 标签

```
<名字>:
```

- 标签可以与前一条语句同行;重复定义报 `E008`,引用未定义标签报 `E007`。

### 6.8 屏障

```
bar()
```

- 展开 `bar.sync`。必须所有 warp 执行相同次数,**不能出现在发散路径里**(`E006`)。
- "均匀"的判据:`tid()`/`wid()`、以及任何由它们或访存结果算出的值是**不均匀**的;
  参数、常量、`-:` 常量与由它们算出的值是均匀的。

## 7. 内置函数

| 函数 | 展开 | 说明 |
|---|---|---|
| `tid()` | `tmov rd, tid` | lane 编号 0...7 |
| `wid()` | `wmov rd, wid` | warp 编号 0...NUM_WARP-1 |
| `ldx(addr)` | `ld.g rd, 0(ra)` | 全局载入(类型由目标变量决定) |
| `lds(addr)` | `ld.s rd, 0(ra)` | 共享载入 |
| `stx(addr, value)` | `st.g 0(ra), rv` | 全局存储 |
| `sts(addr, value)` | `st.s 0(ra), rv` | 共享存储 |
| `ceildiv(a, b)` | `addi rt, rb, -1` / `add rt, ra, rt` / `divu rd, rt, rb` | 向上取整除法(整数;标量循环次数靠它算) |
| `f2i(x)` | `f2i rd, rx` | FP32 → INT32 |
| `i2f(x)` | `i2f rd, rx` | INT32 → FP32 |
| `bar()` | `bar.sync` | 屏障(§6.8) |
| `exit` / `exit()` | `exit` | 退出(必须均匀,§8) |

## 8. 限制

- 无函数调用:一个 `.sg` 文件只有**一个** `kernel`,不可递归。
- 无栈指针:局部变量必须放寄存器;**可用寄存器 31 个**(`r0` 恒零),变量+临时寄存器用尽报 `E001`。
- 谓词只有 `p1..p3`(`p0` 恒真不可写)。`E002`(谓词溢出)**保留但当前不可达**(见 §9)。
- 无字节/半字访存,只有 32 位字;元素地址天然 4B 对齐。
- 无 FP 除法/开方(报 `E012`)。
- 循环次数必须标量(`E005`);`bar()` 必须均匀(`E006`);`exit` 必须均匀。
- 条件是**比较式**或它们的 `&&`/`||` 组合(短路);单个布尔值不能当条件(没有"非零即真")。
- 内核末尾的 `exit` 可以省略:编译器会补一条(否则 PC 会走过镜像末尾)。
- 共享内存 ≤ 16KB/SM,`per_warp` 时 ×4 ≤ 16KB(`E011`);跨 warp 的共享数组必须有 `bar()`(`E013`)。

## 9. 错误码

| 错误码 | 说明 | 触发条件(都有对应反例,见 `make test` 第 ⑬ 节) |
|---|---|---|
| E001 | 寄存器溢出 | 变量 + 表达式临时寄存器超过 31 个 |
| E002 | 谓词溢出 | **保留,当前不可达**(与 ISA §2.6 的 `SIMT_OVF` 同类):复合条件与嵌套 `when` 已改走分支,只有一个 `when` 会长期占住谓词 ⇒ 最多同时用到 2 个。保留它是为了 lowering 变化时能立刻报错 |
| E003 | 未知指令/函数 | 调用未定义函数、参数个数不符、`ldx/lds` 的结果没有被使用 |
| E004 | 类型不匹配 | 跨类型赋值没有 `f2i()`/`i2f()`;未知类型名;`!` 用在非比较式上;把比较式赋值给变量 |
| E005 | 循环次数非标量 | `while` 条件依赖 `tid()`/`wid()` 或访存结果 |
| E006 | 发散路径里 `bar()` | `bar()` 出现在不均匀条件的 `when`/`if`/`while` 体内(或非均匀 `when…goto` 之后) |
| E007 | 未定义标签 | `goto`/`when…goto` 的目标或收敛点标签不存在 |
| E008 | 重复定义标签 | 同名标签出现两次 |
| E009 | 未定义符号 | `@名字` 或 `param … @名字[…]` 里的名字没有 `-:` 定义 |
| E010 | 未对齐地址 | `param`/`@名字[…]` 的偏移不是 4B 对齐的非负字面量;`@名字` 的值未 4B 对齐 |
| E011 | 共享内存溢出 | 共享数组总用量 > 16KB(`per_warp` 按 ×4 计) |
| E012 | FP 除法/开方不支持 | float 的 `/` 或 `%` |
| E013 | 共享内存跨 warp 未同步 | 声明为 `shared` 的数组被访问,但内核里没有 `bar()` |
| E014 | 插入指令非法 | `ass` 后面的助记符不在 ISA.md §5 的指令表里 |

报错格式:`文件:行号: E00x 说明: 具体原因`(如 `abs.sg:12: E004 类型不匹配: x 是 float, 右侧是 int(需要显式 i2f())`)。

## 10. 编译器用法与验证

```bash
cd sw
python3 compiler.py sg/clear.sg -o build/clear.S          # 看生成的汇编(每条指令带注释)
python3 compiler.py sg/clear.sg --image build/clear.bin   # 直接出内核镜像
python3 compiler.py sg/clear.sg --disasm                  # 编译后反汇编(人工核对)
python3 compiler.py sg/*.sg --asm-dir build --image-dir build   # 批量
python3 compiler.py sg/clear.sg --global-base 0x90000000  # __global__ 数组的分配基址
python3 compiler.py sg/clear.sg --stats                   # 编译报告: 布局 + ISA 指令直方图
cd ../sim/simulator && make sg                            # sw/sg/*.sg → build/sg/*.bin
```

**验证方式**(`make test` 第 ⑬ 节,9 条断言):

| 示例 | 验证 |
|---|---|
| `sg/clear.sg` | 与手写 `sw/kernels/clear.S` 画出的 **4096 个像素逐位一致** |
| `sg/abs.sg` | 与手写 `sw/kernels/abs.S` 的 **32 个字逐位一致**(含 -0.0 不算负、NaN 不被取负) |
| `sg/relu_swap.sg` | 共享内存 + 两次 `bar()` + `while` + 谓词化跨 lane 读,与参考 `out[off+i]=|in[off+31-i]|` **64 个字逐位一致** |
| `sg/mask_low.sg` | 位运算/移位(`&` `\|` `>>>`)+ `if/else` + `\|\|` 短路,与参考逐位一致(含 N=32/40 边界) |
| 错误码表 | 13 个可触发码各一个最小反例;`E002` 断言"保留但不可达" |
